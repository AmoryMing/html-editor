# freeze-edit

> 给 AI 生成的 HTML 设计稿做"手工校准"的本地可视化编辑器。
> 冻结动态稿 → 像改 PPT 一样手改 → 保存带备份。零依赖、两个文件、一条命令，附赠局域网多人共编。

AI 可以一分钟生成一张漂亮的 HTML 设计稿，但它永远做不到"只改这一个字，其他都别动"。每次重新生成都会带来微妙的偏移，你调好的"完美版"就再也回不来了。这个工具解决的就是这最后一公里：**AI 负责生成，你负责定稿**。

---

## 适合谁

- **用 Claude / GPT 生成 HTML 设计稿、原型、规格文档的产品经理和设计师**——不用懂前端，浏览器里点选、双击、保存就完事
- **维护"设计基准 / 开发对照规格"的团队**——规格文档需要逐字校准、长期演进，而不是每次重 roll
- **手里攒了一堆版本的人**——v4 的这张卡 + v5 的那张卡 + 新效果稿的图谱，想拼成一份定稿
- 任何想直接改本地 HTML、又不想为此打开 IDE 的人

## 解决什么痛点

| 痛点 | 现状 | 本工具 |
|---|---|---|
| **AI 重新生成 = 偏移** | 让 AI"只改个错别字"，结果整页布局都变了 | 双击文字原位改，其他一个像素都不动 |
| **动态稿根本没法编辑** | Claude artifact 下载的 HTML 是 React/bundler 包，卡片由 JS 运行时渲染，**源码里根本没有那段标记**，文本编辑器打开一片乱码 | 一键「冻结另存」：把渲染后的 DOM 固化成纯静态 HTML（CSS 内联保留，视觉零变化），从此可手改 |
| **跨版本拼装丢样式** | 从 A 版复制一个卡片贴到 B 版，样式全裸奔 | 跨文件剪贴板；从 iframe（srcdoc）里复制时自动连带内部样式，粘贴时加命名空间隔离，两边样式互不打架 |
| **改坏了没后悔药** | 手滑删错一个块，Ctrl+Z 救不了文件 | 每次保存自动备份到 `.bak/<文件名>.<时间戳>.html`，页面内撤销 30 步 |
| **两个人改同一份文件互相覆盖** | 后保存的人把前面的人的活全顶掉 | mtime 冲突锁：文件被别处改过后，旧页面保存会被拒绝并提示刷新，谁的活都丢不了 |

## 如何使用

依赖只有 Node.js（≥16），工具本体就两个文件：`server.mjs` + `editor.js`。

```bash
node server.mjs <HTML所在目录> --port 8787
# 然后浏览器打开（端口被占自动 +1，以终端输出为准）
open http://localhost:8787/
```

索引页列出目录下所有 HTML，并自动标注两类：

- **动态 React / bundler**（artifact 原始包）→ 打开后页面右上角点「冻结另存 ⬇」，生成 `<原名>·静态.html`，源文件永不覆盖
- **静态**（冻结产物或普通 HTML）→ 直接编辑，「保存 ✓」覆盖原文件并自动备份

### 页面内工具条

| 操作 | 怎么做 |
|---|---|
| 选中元素 | 单击（紫框）；`↑父级` 逐级扩大选区；Esc 取消 |
| 改文字 | **双击**任意文字 → 原位编辑 → 点外部或 Esc 结束 |
| 删除 / 排序 | `删除`（或 Delete 键）；`▲▼` 与相邻元素换位 |
| 跨文件复制 | 选中 → `复制` → 切到另一个文件的标签页 → 选中目标 → `替换` / `前插` / `后插` |
| 插入内容 | `+文字` 插入段落；`+截图` 读剪贴板图片（data-URL 内嵌，随文件走） |
| 反悔 | `撤销`（Cmd/Ctrl+Z，30 步）；更早的去 `.bak/` 找回 |
| 动态页取材 | 动态页默认「交互模式」（先点页面把 tab 等状态摆好），Alt+点击或切换按钮进入选择模式 |

iframe（含 srcdoc）内部同样可以点选和双击改字，保存时改动自动写回 srcdoc 属性。

### 典型工作流：跨版本换一张卡

1. 索引页打开来源版本（动态稿先冻结，打开静态版）
2. 点卡片内部 → `↑父级` 扩到整卡边界 → `复制`
3. 新标签页打开目标文档 → 选中要换掉的旧卡 → `替换` → `保存 ✓`
4. 双击微调文字，完成

## 惊喜功能：局域网共编

服务器默认监听所有网卡。也就是说——

```bash
# 你机器上跑着
node server.mjs ./designs --port 8787
# 同事的浏览器直接打开
http://<你的内网IP>:8787/
```

同事看到的是同样的文件列表、同样的工具条，**编辑保存直接落在你的磁盘上**，自动备份照常，mtime 冲突锁保证你俩不会互相覆盖（后保存的人会被提示刷新重改）。

不用装任何东西、不用注册任何服务，一份文件就是单一真相源。评审会上投屏改稿、隔壁工位帮你顺文案，开箱即用。

> ⚠️ 没有鉴权，等于把目录的写权限开放给局域网——只在信任的网络里用，用完 Ctrl+C 关掉。

## 工作原理（30 秒版）

- `server.mjs`：零依赖 Node 静态服务器。给 `?hx=1` 的 HTML 注入编辑器脚本；`POST /__save` 落盘（先备份、校验 mtime）；动态稿冻结时另存新文件
- `editor.js`：页面内覆盖层。捕获点选/双击/快捷键；保存时克隆 DOM、剥离编辑器自身痕迹（冻结模式额外剥离全部 script）后序列化回传；跨文件剪贴板走同源 localStorage，跨文档粘贴时把来源样式加命名空间注入目标文档
- 没有数据库、没有构建步骤、没有外部依赖。两个文件，拷走就能用

## 边界与注意

- **冻结会丢失 JS 交互**（tab 切换、按钮逻辑）——定稿基准本来就该是纯静态；要保留交互的演示稿，保留原动态文件即可（冻结从不覆盖源文件）
- 保存的是 DOM 序列化结果，HTML 格式会被浏览器规范化（属性引号、自闭合标签等），对渲染无影响
- 备份链不是版本管理，重要节点请自己 git
- Chrome / Edge / Safari 现代版均可；剪贴板截图读取需要 localhost 或 HTTPS（localhost 默认满足）

## 文件结构

```
freeze-edit/
├── server.mjs   # 本地服务器（零依赖）
├── editor.js    # 页面内编辑器覆盖层
├── SKILL.md     # （可选）Claude Code 技能描述，让 Claude 帮你启动和驱动编辑
└── README.md
```

`SKILL.md` 是给 [Claude Code](https://claude.com/claude-code) 用的：装到 `~/.claude/skills/freeze-edit/` 后，对 Claude 说"帮我把 v5 的照面卡换进规格文档"，它会启动服务器并通过页面暴露的 `window.__hx` API 代你操作。不用 Claude 也完全不影响工具本身使用。
